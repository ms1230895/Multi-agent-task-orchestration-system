# Starting a new session

Each feature is built in a fresh session. Get oriented before doing anything else.

CLAUDE.md, these rules, and the skill and subagent descriptions load automatically. On your first reply in a session:

1. Read `docs/plans/progress.md` and `docs/plans/roadmap.md`. If a file does not exist yet, say so instead of guessing.
2. Give Gaurav a short orientation, at most 8 lines:
   - **Project:** one line
   - **Done so far:** the last completed step
   - **This session:** the step to work on now (ask if unclear)
   - **Model check:** the recommended model and effort from model-selection.md, and whether the current one matches
   - **VS Code:** connected or not (see vscode-review.md)
3. Wait for Gaurav's go-ahead before editing any file.

Do not re-read a file you have already read in this session.
